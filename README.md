# Hembilder Leverans – uppdateringar

Detta publika repo används enbart för inloggningsfria, versionsbundna installationsfiler till Hembilder Leverans.

Programkällan och byggkedjan ligger inte här. Stabil metadata och de färdiga MSI-, DMG-, AppImage- och DEB-paketen publiceras under **Releases**. Varje installationsfil verifieras mot både exakt byte-storlek och SHA-256 innan appen erbjuder installation.

Den permanenta metadataadressen är:

`https://github.com/Vonsek/hembilder-leverans-updates/releases/latest/download/latest.json`

Drafts och förhandsversioner används aldrig av appens automatiska kontroll.
